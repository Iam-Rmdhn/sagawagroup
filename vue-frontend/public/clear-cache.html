🧹 Clear Cache & Fix Login

Langkah Otomatis:

Langkah Manual (jika masih error):

  1. Chrome/Edge: Tekan Ctrl+Shift+Delete → Pilih "Cached images and files" → Clear
  2. Firefox: Tekan Ctrl+Shift+Delete → Pilih "Cache" → Clear Now
  3. Disable Service Worker:
    • Buka DevTools (F12)
    • Go to Application tab
    • Click Service Workers
    • Click Unregister untuk semua service workers
  4. Test di Incognito/Private Window
